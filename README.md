# Firrhill Advanced Computing

A small PHP website for Firrhill's Advanced Higher Computing course. It introduces the course, outlines the topics covered and provides a simple newsletter sign-up and members area.

## Features

- Course information and useful revision links
- Newsletter email sign-up
- Login and logout using PHP sessions
- Members-only page covering Web Design and Development (WDD) and Software Design and Development (SDD)

## Built With

- PHP
- HTML
- CSS
- MySQL

## Project Files

- `index.php` – course homepage
- `signup.php` – newsletter sign-up
- `login.php` / `logout.php` – session-based login
- `members.php` – members-only course information
- `connect.php` – MySQL database connection
- `style.css` – website styling
